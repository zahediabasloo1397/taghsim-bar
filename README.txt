# سایت سیستم تقسیم بار

## اجرا
فایل `index.html` را با مرورگر باز کنید. سایت به صورت محلی و بدون سرور کار می‌کند و اطلاعات تغییر داده‌شده را در LocalStorage مرورگر ذخیره می‌کند.

## امکانات
- انتخاب و جستجوی کارخانه، مبدأ و مقصد
- تناژ ۲۵ تا ۱۰۰٬۰۰۰ تن با گام ۲۵
- تقسیم بار بر اساس کرایه، عقب‌ماندگی یا ترکیبی
- تعریف و جستجوی کرایه پایه برای شهر و کارخانه
- ۱۹ شرکت با سهم مستقل برای ۳ کارخانه
- ثبت سوابق بار و محاسبه تناژ قبلی
- جستجوی نتایج
- خروجی و ورود فایل پشتیبان JSON

برای استفاده چندکاربره و آنلاین، همین رابط می‌تواند به یک سرور و پایگاه‌داده (مثلاً Node.js + PostgreSQL) متصل شود.
